# EchoAlarm

**EchoAlarm** is a simple countdown timer written in Python. It takes user input for the duration, counts down in seconds, plays an alarm sound when time is up, and sends a desktop notification.

## Features

- User input for countdown duration in seconds  
- Real-time countdown display in MM:SS format  
- Plays a sound when the timer ends  
- Sends a desktop notification upon completion

---

## Requirements

- Python 3.x
- [`playsound`](https://pypi.org/project/playsound/)
- [`plyer`](https://pypi.org/project/plyer/)

### Install Dependencies

Use `pip` to install the required libraries:

pip install playsound plyer
